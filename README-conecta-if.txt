CONECTA IF — O IF acontece. Conecte-se!

COMO ABRIR:
1. Baixe conecta_if.html.
2. Dê dois cliques no arquivo para abrir no navegador.
3. As imagens são carregadas de URLs externas e exigem internet.

COMO ENVIAR AO GITHUB:
1. Abra seu repositório Conecta-IF.
2. Clique em Add file > Upload files.
3. Envie conecta_if.html.
4. Para o GitHub Pages reconhecer a página inicial automaticamente, renomeie o arquivo para index.html antes do envio (ou renomeie-o no próprio GitHub).
5. Clique em Commit changes.
6. Vá em Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMPORTANTE:
Este é um protótipo visual e interativo. Os projetos, eventos e avisos são exemplos demonstrativos. O formulário salva os avisos localmente no navegador, não em um banco de dados compartilhado. Antes de uso institucional, implemente autenticação, banco de dados, permissões, moderação e regras de segurança. O projeto ainda não possui homologação oficial do IF Goiano.
